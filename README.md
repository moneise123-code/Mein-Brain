# Mein Brain – J.A.R.V.I.S.

Persönliches Command Center als eigenständige HTML-Datei (`index.html`).

- Bereiche: Overview, Assistant, Business, Trading, Research, Aufgaben, System & Daten
- Speichert Aufgaben, Ideen, Trading-Notizen und Chatverlauf lokal im `localStorage` des Browsers
- Keine externen Verbindungen, kein KI-Modell, keine Broker-Anbindung

## Nutzung

`index.html` einfach im Browser öffnen. Über „System & Daten“ lassen sich die Daten als JSON exportieren oder löschen.
